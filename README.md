# spicy-review スキル（社内共有用）

Claude Code で「計画や設計をしつこく質問して詰めてもらう」ためのスキルです。
AIanime_Production で使っていた `grill-me` を、このリポジトリに移して社内向けに調整したものです。

## 何をするスキルか

自分の計画・設計・判断を Claude に説明すると、Claude が「まだ決まっていないこと」を洗い出して質問してきます。

- 質問は **ラウンド** 単位で出ます。1ラウンドは最大3問です。
- 各質問には、番号・「なぜこの質問が重要か」・Claude の推奨案が付きます。
- 答えると、その答えを前提にした次の質問が出ます。
- 聞くことが無くなったら終わりです。最後に「決まったこと」の一覧が出ます。
- **Claude は勝手に実装に進みません。** 「共通の理解に達した」と自分が言うまで質問だけを続けます。

「なんとなく決めたつもりになっていたこと」を、作り始める前に見つけるのが目的です。
UI の改修計画、データの持ち方、工程の分担などを決めるときに使えます。

## 使い方

Claude Code のセッションで、次のどちらかで始まります。

1. `/spicy-review` と打って、そのあとに詰めたい内容を書く
2. 普通の会話で「とことんレビューして」「激辛レビューお願い」「質問攻めにして」「考えの穴を探して」などと言う

例:

```
/spicy-review 承認フローを作りたい。承認者はカットごとに1人、承認したら場面写は差し替えられないようにする予定。
```

質問は本文中に書式付きで出ます（選択肢を選ぶ画面のようなツールは使いません）。
`Q1: a` `Q2: b、ただし〜` のように、記号や短い文で答えれば大丈夫です。
答えは要約されず原文のまま扱われるので、口語のままで構いません。

## 入れ方

### A. このリポジトリで使う場合

`.claude/skills/spicy-review/SKILL.md` にあるので、このリポジトリを clone して Claude Code を開けば、そのまま使えます。

### B. 自分の別のプロジェクトで使う場合

`.claude/skills/spicy-review/` フォルダごと、使いたいプロジェクトの `.claude/skills/` にコピーしてください。

```
cp -r .claude/skills/spicy-review  <使いたいプロジェクト>/.claude/skills/
```

### C. どのプロジェクトでも使えるようにする場合

自分のホームフォルダ側に置くと、全プロジェクトで使えます。

```
mkdir -p ~/.claude/skills
cp -r .claude/skills/spicy-review  ~/.claude/skills/
```

## 元との違い（調整した点）

元は `grill-me`（入口）と `grilling`（本体）の2つのスキルに分かれていました。ここでは `spicy-review` という1つのスキルにまとめています。
中身の進め方（設計木・ラウンド・フロンティア・事実は Claude が調べて判断はユーザーがする）は元のままです。
社内向けに足したのは次の点です。

- 会話を日本語（です・ます調、硬すぎない）で行う
- 制作スタッフも読む前提で、たとえ話やかっこつけた言い回しを使わない
- 1ラウンドの質問は最大3問にする
- 各質問に「なぜこの質問が重要か」を添える
- 質問は本文中の書式で出し、選択肢を選ぶ画面のようなツール（AskUserQuestion など）は使わない
- 選択肢に a / b / c を振って、記号だけで答えられるようにする
- 回答は要約せず原文のまま扱い、まとめでも「原文」と「帰結」を分ける
- 終了時に「質問番号・回答原文・帰結」の一覧を出す
